# C8Play — STM32F103C8T6 掌机（FreeRTOS）

一个基于 STM32F103C8T6（ DshanMCU-F103 板）与FreeRTOS的迷你掌机项目：OLED 屏幕 + 红外遥控 / 编码器 / MPU6050 体感三种输入，内置 俄罗斯方块、贪吃蛇、打砖块 三款游戏，最高分存入板载 W25Q64 Flash（双槽防断电丢档），并通过 UART自定义协议 与 PC 联调（命令控制 + 状态上报）。

## 1. 硬件

| 外设 | 型号/引脚 | 说明 |
|---|---|---|
| 主控 | STM32F103C8T6 | 64KB Flash / 20KB RAM，72MHz |
| 屏幕 | 0.96" SSD1306 OLED（I2C） | 128×64，I2C1，**400kHz 快速模式** |
| 姿态 | MPU6050（I2C 同总线） | 体感倾斜控制；离线 3s 退避防拖死 OLED |
| 红外 | HS0038B（PB10） | 遥控输入，键码→语义事件翻译 |
| 编码器 | EC11（PB0/PB12，按键 PB1） | 菜单/游戏方向输入 |
| 按键 | K1（PB14） | 确认 / 长按返回 |
| 蜂鸣器 | 有源（PA8，低电平驱动） | 游戏音效（短/长音组合） |
| 全彩 LED | 共阴 RGB（TIM2 三通道 PWM） | 菜单绿 / 游戏蓝 / 结束红闪 |
| 温湿度 | DHT11（PA1） | 桌面模式显示，2s 刷新 |
| 光敏 | 光敏电阻 + ADC1_IN3（PA3） | 桌面模式显示光强 |
| 存储 | W25Q64（SPI1，8MB） | 最高分双槽存档 |
| 串口 | USART1（PA9/PA10, 115200） | PC 联调协议通道 |

### 自研模块（Core/）

## 5. UART 协议（与 PC 联调）

帧格式：`AA 55 | LEN | CMD | DATA[LEN] | CRC8 | 0D`（CRC8 多项式 0x07，覆盖 LEN..DATA 末位）。

| CMD | 功能 | 说明 |
|---|---|---|
| 0x01 | 读设备信息 | 应答：型号 C8PL + 固件版本 + 协议版本 |
| 0x02 | 读最高分 | 应答：3×uint16 LE（俄/蛇/砖） |
| 0x03 | 清存档 | 危险命令，双槽全 0 |
| 0x05 | 切模式 | DATA[0]=0菜单/1俄/2蛇/3砖 |
| 0x06 | 游戏控制 | DATA[0]=1右/2左/3确认/4硬降/5返回 |
| 0x07 | 状态上报（主动）| 掌机 → PC：切模式/破纪录实时推送 |
| 0x81 | 应答（下行） | DATA[0]=错误码（00 成功/01 未知/02 参数错） |

详细文档见 `UART协议文档.md`。

## 6. 系统架构（FreeRTOS）

```
input_task    AboveNormal (10ms 节拍)：编码器/按键/红外/MPU6050 → 事件队列（I2C 互斥）
gameTask      Normal      (33ms 节拍)：消费事件 + 游戏帧 + 增量渲染（I2C 互斥，防抖 8ms 冻结）
housekeeping  Low         (100ms 节拍)：DHT11/光敏分频采样、存档脏标志落盘、LED/蜂鸣器刷新
protoTask     Normal      (阻塞收队列)：USART1 收帧 → 解析/CRC → 命令分发 → 应答（UART 发送互斥）
```

要点：
- **中断只放接收/时基，全部业务在任务中轮询**（红外/编码器消抖在任务层，不用 EXTI 回调）。
- **I2C/SPI/UART 三把互斥量** + 优先级继承，杜绝总线并发与锁踩踏。
- **慢操作移出游戏帧**：Flash 擦写只在"脏标志"置位后的 housekeeping 节拍执行。

## 8. 曾遇到的问题

1. **HAL_UART_Transmit 与中断接收锁踩踏** → 应答帧丢失；改为寄存器级直写绕过 HAL 锁。
2. **MPU6050 晃动卡死** → 裸机不卡、FreeRTOS 卡：锁定 I2C 锁/中断优先级；最终用"离线退避 + 冻结自愈"根治。
3. **断电丢档** → 单槽擦除窗口掉电毁档；改双槽 + 序列号 + 先擦旧槽，任何时刻最多丢旧纪录。
4. **512B 任务栈溢出** → 静默破坏内存随机卡死；改用高水位实测调栈（4608→2048B，省 55%）+ `configCHECK_FOR_STACK_OVERFLOW=2` 溢出检测兜底。
5. **OLED 整屏刷屏 30ms 占帧** → 增量渲染（脏列），静止 0 传输。
6. **I2C 卡死死等** → 每页 30ms 超时 + 500ms 外设复位自愈。

## 9. 已知边界

- 无 RTC，桌面模式不显示时钟。
- SETTINGS 仅提供清档确认；音量/亮度界面为预留。
- 存档最高分为 uint16（上限 65535，实际游戏远达不到）。
- 未用韦东山驱动（DS18B20/超声波/电机/无源蜂鸣器等）文件保留在 Drivers 下，但已在工程中 Exclude from build，不占 Flash。
